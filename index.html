⚠️ HTTPS 页面的 mixed-content 限制（重要）

本页经 GitHub Pages 以 https 提供。浏览器会拦截 https 页面直连 http 明文推理端点（如 http://内网机:8080/v1）。两种绕法：
  • 本地打开：clone/下载仓库后双击 standalone.html（file:// 无此限制），或自建 http 页面 —— 测内网 http 端点用这个
  • 端点支持 https：公网 https 端点（OpenAI 官方等）在本页可直连，无障碍

端点 CORS 要求

浏览器直连要求端点返回 CORS 头（测试台失败时会给出同样提示）：
服务端开启方式
vLLM--allow-origins '*'
llama.cpp server / llama-swap--origins '*'
OpenAI 官方 API本身即支持

五个测试任务

  • T1 单针 NIAH 网格：随机码针 × 长度 × 深度 → 召回热图；lost-in-the-middle 与有效上下文边界
  • T2 五针全召回：5 根针分散全篇，全找出来才算过（多目标检索广度）
  • T3 三跳事实链：三个事实分散三处，必须串联推理（检索 ≠ 推理）
  • T4 计数聚合：短语插 7 次问次数（验证注意力贯穿全文）
  • T5 强制长文生成：长输出探针，检测 loop 复读与 caveman 电报体退化
